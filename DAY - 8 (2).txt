Question :- What is subnetting? What is the use of subnetting?
Ans :- Subnetting is dividing a large network into smaller, more efficient subnetworks. It helps improve performance, security, and management.

1. Understanding an IP Address
   - An IPv4 address is a 32-bit number, divided into 4 octets (each 8 bits). Example:
     - 192.168.1.1 → 11000000.10101000.00000001.00000001 (binary)
     - Each octet ranges from 0 to 255.

2. Subnet Mask – What Is It?
   - A subnet mask defines how many bits belong to the network and how many to the hosts. Example:
   - Default Subnet Masks:
     
	 Class	   Default Subnet Mask	    CIDR	   # of Hosts
      A	       255.0.0.0	             /8	       16,777,214
      B	       255.255.0.0	             /16	   65,534
      C	       255.255.255.0	         /24	   254
   - CIDR (Classless Inter-Domain Routing) is another way of writing a subnet mask using a slash notation (/24 means first 24 bits are network bits).
   
   - Types of Subnetting in IPv4 :- Subnetting can be categorized into different types based on how subnets are created and used. There are two main types of subnetting:
     1. Fixed-Length Subnetting (FLSM - Fixed-Length Subnet Masking)
     2. Variable-Length Subnetting (VLSM - Variable-Length Subnet Masking)
   
   1. Fixed-Length Subnet Mask (FLSM)
   - What is FLSM?
      - In FLSM, all subnets are created with the same number of hosts by dividing the network into equal-sized subnets.
      - Each subnet has the same subnet mask.
      - IP addresses are evenly distributed but can lead to wasted addresses if not all subnets require the same number of hosts.
   - Example of FLSM Subnetting:
      - Given 192.168.1.0/24 (Class C network, 254 usable hosts).
      - We want 4 subnets → Need to borrow 2 bits (/26 subnet mask).
      - Each subnet has 64 total addresses (62 usable hosts).
      - Even if a subnet needs only 10 hosts, it still gets 62 (leading to IP wastage).
   - When to Use FLSM?
      - Simple network designs where all subnets need an equal number of hosts.
      - Used in old routing protocols like RIP v1, which do not support VLSM.
   
   2. Variable-Length Subnet Mask (VLSM)
   - What is VLSM?
     - VLSM allows subnetting with different subnet masks to allocate IP addresses more efficiently.
     - It assigns different subnet sizes based on host requirements.
     - Minimizes IP wastage by giving larger subnets more addresses and smaller subnets fewer.
     - Supported by modern routing protocols (OSPF, EIGRP, RIPv2, BGP).
   - Example of VLSM Subnetting:
     - Given 192.168.1.0/24 (254 usable hosts).
     - Instead of splitting equally (like FLSM), we divide based on need:
	   Subnet	            Hosts Needed	Subnet Mask	     Network Address    Usable IPs	                     Broadcast Address
       Subnet 1 (Large)	    100	            /25 (128 IPs)	 192.168.1.0	    192.168.1.1 - 192.168.1.126	     192.168.1.127
       Subnet 2 (Medium)	50	            /26 (64 IPs)	 192.168.1.128	    192.168.1.129 - 192.168.1.190	 192.168.1.191
       Subnet 3 (Small)	    25	            /27 (32 IPs)	 192.168.1.192	    192.168.1.193 - 192.168.1.222	 192.168.1.223
       Subnet 4 (Small)	    10	            /28 (16 IPs)	 192.168.1.224	    192.168.1.225 - 192.168.1.238	 192.168.1.239
	   
	- Advantages of VLSM:
      - More efficient IP address usage (no wasted IPs like in FLSM).
      - Better suited for real-world networks with varying host requirements.
      - Allows hierarchical addressing, improving routing efficiency.
    - When to Use VLSM?
      - When different subnets need different host counts.
      - When using routing protocols like OSPF, EIGRP, or RIPv2.


   - Key Differences: FLSM vs. VLSM
     Feature	         FLSM (Fixed-Length)	  VLSM (Variable-Length)
     Subnet Size	     All subnets are equal	  Subnets have different sizes
     IP Wastage	         High (unused IPs)	      Low (efficient use of IPs)
     Routing Protocols	 Works with RIPv1	      Works with OSPF, EIGRP, RIPv2
     Best for	         Simple networks	      Complex, scalable networks
     Example	         4 subnets of /26	      Different subnet masks used

- What is Supernetting?
Ans :- Supernetting is a technique used to combine multiple smaller networks into a larger network. It reduces the number of routing table entries, making routing more efficient.

Supernetting is also called:
 - Route Aggregation
 - Route Summarization
